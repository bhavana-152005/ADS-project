# ADS-project
This project is an end-to-end data engineering pipeline built using the Adventure Works dataset, designed to demonstrate how raw business data can be transformed into meaningful insights using modern cloud technologies. 
The project is built using the Medallion Architecture, which consists of:

Bronze Layer → Raw data ingestion
Silver Layer → Cleaned and transformed data
Gold Layer → Aggregated and analytics-ready data
Tech Stack:
Azure Data Factory (ADF) – Data ingestion and orchestration
Azure Data Lake Storage (ADLS) – Data storage
Azure Databricks (PySpark) – Data transformation
Azure Synapse Analytics – Data warehousing
